# 合法使用说明

<p class="lead">本篇说明归档资料前需要确认的使用范围，以及获取、保存和转交资料时应注意的事项，帮助你在整理公告的同时，遵守来源网站、资料授权和保密要求。</p>

## 1. 归档前，确认资料可以用于哪些用途 {#check-use}

先明确这次保存资料是为了什么，例如项目留档、内部核对或向客户提供项目资料。再阅读原公告、附件和来源网站的使用说明，确认你的用途有合法依据，并已取得所需授权。涉及单位或客户资料时，还要遵守相应的保密约定。

**资料能够公开查看，不等于可以不受限制地保存、复制、转交或公开。** 需要额外授权时，请先完成授权，再处理对应资料；不确定可使用的范围时，可以向资料发布方或单位负责该项目的人员确认。

<details class="custom-block details" open>
<summary>补充说明</summary>

工作台中的 **“一键归档下载”** 按钮可用，表示当前页面已被支持，可以发起归档。它不会替你判断资料权属，也不代表你已经取得复制、转交或公开这些资料的授权。服务范围与使用要求见[服务协议](/terms/#section-3)。

</details>

## 2. 获取资料时，遵守原网站的访问要求 {#source-access}

原网站要求登录、输入验证码或申请附件访问权限时，请先按网站提示完成。公告要求通过指定平台、邮箱或现场获取的文件，也应按原公告指引取得。

请根据本次工作需要选择公告，由你主动发起归档。**不要绕过登录、验证码、下载权限或访问频率限制，也不要利用插件不受限制地批量抓取资料。** <span class="product-name">采标集</span>不会代替你完成原网站的验证或取得额外权限。具体访问说明见[支持范围与权限](/manual/supported-sites/#access-requirements)。

<details class="custom-block details" open>
<summary>补充说明</summary>

附件在原网站也打不开时，先查看网站提示；无法自行处理的，可以联系原网站管理员协助核查。购买<span class="product-name product-name--after-text">采标集</span>套餐或授予浏览器权限，都不能替代原网站要求的访问授权。

</details>

## 3. 归档后，核对内容并妥善保存 {#check-and-store}

### 使用前核对来源和内容 {#verify-content}

归档完成后，请打开 ZIP 归档包，核对项目名称、编号、来源页面及附件内容，确认资料符合本次需要。具体检查步骤见[归档包与内容核对](/manual/archive-output/)。

归档包保留的是本次归档时取得的资料。之后将其用于采购、投标或其他业务前，请回到来源网站确认是否有更正、补充或其他更新，并以原网站发布的信息为准。

<details class="custom-block details" open>
<summary>补充说明</summary>

归档详情显示 **“已保存”**，表示归档包已经保存到电脑，不表示资料已经通过真实性、完整性或用途合规性的专业核验。<span class="product-name">采标集</span>提供资料整理与本地归档，不替代原公告和你的业务判断。

</details>

### 按资料要求保管文件 {#protect-files}

保存的资料中如有个人信息、商业秘密或其他受保护内容，请放在符合单位或项目要求的存储位置，并限制无关人员访问。使用共享文件夹或网盘时，确认哪些人可以查看、下载，避免误设为公开分享。

资料的保留期限和删除方式，应按适用规定、业务需要及保密要求确定。目的完成后，请检查是否仍需依法留存，再处理不再需要的副本。文件与浏览器记录的保存方式见[本地数据与文件保存](/manual/local-data/)。

<details class="custom-block details" open>
<summary>补充说明</summary>

公告正文、截图、附件和归档包在你的设备中处理，不会作为归档内容上传至<span class="product-name product-name--punctuation product-name--after-text">采标集</span>服务器。你自行复制到网盘或发送给他人时，仍需确认该存储位置或接收方符合资料的使用要求。具体信息处理方式见[隐私政策](/privacy/#section-2)。

</details>

## 4. 转交或公开前，再确认提供范围 {#before-sharing}

准备将资料发给同事、客户，或上传到网站、共享空间前，请先确认接收方、使用目的和需要的内容都在允许范围内，只提供完成这件事所需的资料。

发送前，检查文件和截图中是否含有与本次用途无关的个人信息、客户资料或保密内容。可以删去或遮挡不需要提供的内容，但不要因此改变公告原意；无法确认是否可以提供时，先向资料发布方或单位负责人员核实。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **资料中的个人信息已经公开：** 公开并不意味着可以用于任何目的。例如，公告中的业务联系电话不应被随意收集用于无关营销。相关说明可参阅[国家网信办关于已公开个人信息的问答](https://www.cac.gov.cn/2026-08/12/c_1788195297373459.htm)。
- **向技术支持反馈问题：** 提供问题说明和必要的局部截图即可，先遮挡无关信息。不要发送密码、验证码、完整兑换码、标书附件或完整 ZIP 归档包。具体准备方法见[联系技术支持](/manual/support/#prepare-feedback)。

</details>

完整的服务范围、双方责任和个人信息处理规则，请查看[服务协议](/terms/)与[隐私政策](/privacy/)。
