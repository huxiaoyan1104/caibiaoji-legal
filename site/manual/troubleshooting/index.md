# 常见问题

<p class="lead">本篇整理归档过程中常见的提示和处理方法，帮助你排查无法开始归档、归档失败、等待保存，以及找不到记录或文件等问题。</p>

## 1. 无法开始归档时 {#cannot-start}

### “一键归档下载”按钮为什么不能点击？ {#archive-button}

先看工作台当前显示的提示：

- **“正在读取当前页面”：** 等待读取完成，再查看按钮状态。
- **提示已有任务正在归档：** 点击 **“查看当前任务”** 查看进度，等任务结束后再开始新的归档。
- **“当前页面不可归档”：** 先回到网站，打开能看到公告标题和正文的页面，再查看工作台。**“一键归档下载”按钮可点击，就表示当前页面已受支持，可以发起归档。**

如果你需要的公告仍提示暂不支持，欢迎[联系技术支持](/manual/support/)，提供公告网址和希望归档的资料。支持站点及访问要求见[支持范围与权限](/manual/supported-sites/)。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **工作台加载失败，或暂时无法确认支持哪些页面：** 按页面提示检查网络并点击 **“重试”**。仍无法读取时，请提供当前提示和插件版本，[联系技术支持](/manual/support/)。
- **点击后要求登录：** 按提示完成登录即可。验证码、密码或登录失败的问题，见[登录与密码](/manual/account/)。

</details>

### 提示“权益不足，暂未归档”，接下来怎么办？ {#entitlement-required}

这表示公告信息已经解析，但还没有开始下载附件，也没有生成归档包。要继续处理这份公告：

1. 点击归档详情中的 **“升级 / 兑换码”**，按[购买与兑换](/manual/purchase/)补充当前账号的归档权益。
2. 权益到账后，返回这条归档详情，点击 **“继续归档”**。如果已经离开详情页，可以从 **“归档历史”** 找到这条记录再打开。
3. 等待详情显示 **“已保存”**，再查找并核对归档包。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **已购买，仍提示没有可用权益：** 先确认是否已将爱发电私信中的兑换码兑换到当前登录的账号。付款后还需要完成兑换，具体步骤见[购买与兑换](/manual/purchase/#redeem-code)。
- **提示权益刷新失败：** 点击 **“重新刷新权益”**，更新后再查看是否可以继续归档；仍不一致时，请[联系技术支持](/manual/support/)。
- **继续归档时无法读取原公告：** 先打开原网页，确认公告内容能正常显示，再返回这条详情点击 **“继续归档”**。如果提示公告与原记录不对应，请核对网址和项目编号，并联系技术支持。

</details>

## 2. 归档失败时 {#archive-failed}

### 提示“未识别到项目编号”，怎么办？ {#project-number}

<span class="product-name">采标集</span>需要项目编号才能继续归档。出现这条提示时，本次任务已经停止，附件尚未下载，也没有生成归档包。

1. 点击 **“查看原网页并核对项目信息”**，检查原公告正文是否显示完整，以及是否写有项目编号。
2. 如果原网页还没有加载完成，或要求登录、完成验证码验证，先按原网站提示处理，确认正文可以正常查看后，再回到工作台重新归档。
3. 原文中有项目编号，仍无法识别时，请[联系技术支持](/manual/support/)，提供公告网址和包含编号的局部截图。

<details class="custom-block details" open>
<summary>补充说明</summary>

如果原公告本身没有项目编号，当前版本无法继续归档这份公告。可以将公告网址发给技术支持，说明你的归档需求。

</details>

### 附件下载失败，怎么办？ {#attachment-failed}

在归档详情的 **“文件清单”** 中，找到标记为 **“未归档”** 并显示失败说明的附件，记下文件名，再按下面的顺序检查：

1. 回到原公告，打开对应的附件链接，确认能否正常获取文件。
2. 原网站要求登录、验证或申请访问权限时，先按网站提示完成。附件在原网站也打不开时，需要先解决原网站的访问问题。可以联系原网站管理员协助核查。
3. 确认原公告和附件都能正常访问后，回到工作台重新发起归档。仍失败时，请[联系技术支持](/manual/support/)，提供公告网址、附件名称和失败提示。

本次归档会处理页面中识别到的全部公开附件。**只要还有附件未能下载，就不会生成完整归档包**；不能通过跳过失败附件完成本次归档。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **失败发生在“确认可用权益”这一步：** 这与附件下载失败不同，请按归档详情中的 **“联系技术支持”** 入口反馈当前提示。
- **担心失败后扣了次数：** 归档失败或取消不会扣减按次权益；已经生效的按时套餐仍会继续计时。具体规则及记录核对方法见[权益使用规则](/manual/entitlements/)。
- **显示“未发现公开附件”：** 这不等于附件下载失败。公告要求通过其他平台、邮箱或现场获取的文件，需要按原公告指引取得；归档包中内容的核对方法见[归档包与内容核对](/manual/archive-output/#read-files)。

</details>

## 3. 附件下载完，仍未显示“已保存”时 {#waiting-for-save}

附件下载完成后，还需要生成 ZIP 归档包，再通过浏览器保存到电脑。请先查看归档详情中的当前状态：

| 当前状态 | 接下来怎么做 |
| --- | --- |
| 正在生成归档包 | 等待公告原文、清单和附件打包完成 |
| 正在保存 | 查看浏览器是否弹出保存位置选择窗口；如有，选择位置并确认保存，再等待下载完成 |
| 已保存 | 点击“在文件夹中显示”，找到本次 ZIP 归档包 |

**文件清单中的“已下载”只表示附件下载完成，整次归档是否完成要以“已保存”为准。**

如果长时间停留在 **“正在保存”**，可以打开浏览器的下载列表，查看本次 ZIP 归档包的状态。下载显示失败或中断时，先查看对应提示；仍无法处理，或下载已完成但详情一直未更新时，请[联系技术支持](/manual/support/)，提供归档详情和浏览器下载状态的截图。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **长时间停留在“正在生成归档包”：** 请记录当前状态和附件数量，联系技术支持协助排查。浏览器下载列表用于检查保存阶段，不能据此判断打包是否完成。
- **任务尚未结束时：** 请先保留原公告页面，不要通过卸载插件或清除扩展数据来排查。清理数据会删除本地记录，具体影响见[本地数据与文件保存](/manual/local-data/#before-changes)。

</details>

## 4. 找不到记录或文件时 {#missing-record-or-file}

### 以前的归档记录为什么不见了？ {#missing-history}

先回到归档时使用的电脑和浏览器，登录当时使用的<span class="product-name product-name--after-text">采标集</span>账号，再打开 **“归档历史”**：

1. 清空搜索框，将状态改为 **“全部状态”**，时间改为 **“全部时间”**，确认记录是否被筛选条件隐藏。
2. 如果提示加载失败，点击 **“重试”**，重新加载记录。
3. 仍找不到时，回想是否更换过浏览器环境、卸载过插件或清除过扩展数据，再按下方说明检查。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **换了电脑或浏览器环境：** 即使登录同一账号，也不会自动显示原来的归档历史。需要回看时，请在原浏览器环境中查看。
- **卸载过插件或清除过扩展数据：** 原环境中的本地归档记录会被删除，重新安装并登录不能恢复；已经保存到电脑的 ZIP 归档包仍可以到文件夹中查找。详见[本地数据与文件保存](/manual/local-data/)。

</details>

### 记录还在，但“在文件夹中显示”找不到文件？ {#missing-file}

先确认打开的是已完成的归档记录，再按下面的顺序查找实际文件：

1. 到本次选择的保存位置查找。没有调整保存位置时，通常在浏览器下载目录下的 `采标集` 文件夹中。
2. 如果后来移动或重命名过归档包，到新位置查找，也可以用系统文件搜索查找文件名。
3. 找到后，打开 ZIP 归档包并核对项目，确认它是本次需要的文件。具体方法见[归档包与内容核对](/manual/archive-output/)。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **清理过浏览器下载记录：** 对应记录被清理后，无法再通过“在文件夹中显示”定位文件，但已下载的文件仍保留在电脑中。
- **文件已经删除：** 可以检查系统回收站或自己保存的副本。归档历史不能恢复已经删除的 ZIP 归档包。
- **文件找到了，但打不开或内容不完整：** 请按[归档包与内容核对](/manual/archive-output/)检查清单、原文和附件；需要反馈时，说明异常文件及具体提示即可。

</details>

按对应步骤检查后仍未解决，请[联系技术支持](/manual/support/)，说明公告网址、出问题的步骤和当前提示。版本信息及截图准备方法见该页的[反馈说明](/manual/support/#prepare-feedback)。
