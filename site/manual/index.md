# 认识采标集

<div class="brand-statement">
  <p class="brand-statement-label">品牌主张</p>
  <p class="brand-statement-slogan"><span class="brand-statement-part">把整理交给<span class="product-name product-name--punctuation product-name--after-text">采标集</span>，</span><span class="brand-statement-part">把全力留给项目。</span></p>
</div>

<p class="lead"><span class="product-name">采标集</span>是一款政府采购公告归档助手，帮助你快速整理公开招标公告及其附件，减少逐个下载、重命名和制作清单的重复工作。</p>

## 用“一键归档下载”完成资料整理

手动整理一份采购公告时，你通常需要在公告网页、下载文件夹和表格之间来回切换。先保存公告正文，再逐个下载附件、整理文件名，最后把项目名称、编号和来源网址录入清单。处理下一份公告时，又需要重复这些操作。

为了减少这些重复工作，<span class="product-name">采标集</span>把上述整理步骤集中到一次 **“一键归档下载”** 操作中。

在支持的公告详情页，登录<span class="product-name product-name--after-text">采标集</span>并确认页面可归档后，点击 **“一键归档下载”** 按钮即可发起归档。接下来，<span class="product-name">采标集</span>会自动完成公告保存、附件下载、文件整理、清单生成和打包保存。等到归档详情显示“已保存”，点击“在文件夹中显示”，就能找到 ZIP 归档包，解压后即可查看和核对资料。

具体来说，同样一份项目资料，手动整理与使用“一键归档下载”的区别如下：

总之，你可以**一次点击发起归档，把后续整理交给<span class="product-name product-name--punctuation product-name--after-text">采标集</span>**，减少在网页、文件夹和表格之间反复操作。归档过程中，你可以在归档详情中查看进度；保存完成后，再核对清单和文件。

## 整理后的资料，便于核对和留存

归档完成后，<span class="product-name">采标集</span>会把公告原文、Excel 归档清单和成功下载的公开附件打包为一个 ZIP 归档包保存到电脑。将 ZIP 归档包解压后，清单、原文和附件各有固定的位置，查找资料时可以按下面的目录逐项查看。

公告原文也可能保存为 `01_网页原文.jpeg`（图中以 PDF 为例）。如果本次未识别到可直接下载的公开附件，附件文件夹会显示为 `02_附件_原网页无附件`。

### 先看清单，再打开对应文件

有了这份目录，核对时就可以先从 `00_归档清单.xlsx` 入手，确认项目和资料来源，再按清单找到对应文件：

1. **先确认是哪一个项目。** 在“归档概览”中，查看项目名称、项目编号、标段／包号、来源页面和归档时间。需要回到原公告核对时，可以按“来源页面”记录的网址查找。
2. **再对照附件名称找文件。** 切换到“附件清单”，查看每个附件的原始文件名、归档文件名、来源地址和处理状态，再到 `02_附件/` 打开对应文件。例如，清单中的归档文件名是 `001_采购需求.pdf`，就可以在附件文件夹中找到同名文件。
3. **需要回看公告内容时，打开网页原文。** `01_网页原文.pdf` 或 `01_网页原文.jpeg` 保存了归档时的公告主要内容，可以与清单中的项目信息对照查看。

### 核对完成后，按项目留存

确认文件能打开、内容与所需资料相符后，再把 ZIP 归档包或解压后的文件夹放进对应项目目录中，并将清单、原文和附件一同保留。这样，以后再次使用这份资料时，既能找到文件，也能通过清单查到它来自哪份公告、归档后的名称是什么。
