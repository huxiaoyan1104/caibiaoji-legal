# 联系技术支持

<p class="lead">使用<span class="product-name product-name--after-text">采标集</span>时遇到问题，或想提出功能建议，可以通过小红书私信或邮件联系我。</p>

## 1. 选择联系方式 {#contact-methods}

### 小红书私信 {#xiaohongshu}

你可以通过小红书私信咨询使用方法、反馈问题，或提出功能建议。点击[打开小红书主页](https://xhslink.cn/o/Es2QXxkPhE)，也可以使用小红书“扫一扫”扫描下方二维码，进入主页后发送私信。

### 邮件反馈 {#email}

将问题发送至 [support@fun8.top](mailto:support@fun8.top)。点击邮箱地址可打开邮件应用，也可以复制地址，粘贴到你常用邮箱的收件人栏。

邮件主题建议写为 **“采标集反馈｜问题简述”**，例如“采标集反馈｜附件下载后一直显示正在保存”。正文可使用下方反馈模板。

服务时间：**周一至周五 09:00–18:00（北京时间）**。

<details class="custom-block details" open>
<summary>补充说明</summary>

- **小红书主页或二维码暂时无法打开：** 可以改用上方邮箱反馈问题。
- **申请退款：** 请通过邮件提交，并按[退款协议](/refund/#section-5)中的要求选择发件邮箱、准备申请资料。小红书私信可用于咨询，正式退款申请仍需通过邮件提交。
- **申请注销账号或处理个人信息：** 请通过邮件提出申请，具体要求见[隐私政策](/privacy/#section-7)。

</details>

## 2. 说明问题，附上必要信息 {#prepare-feedback}

选好联系方式后，请先说明你原本想完成什么、操作到了哪一步，以及实际出现的情况。如果页面有错误提示，可以附上提示原文或必要截图；归档问题还可以提供对应的公告网址。

为了便于核对使用环境，请补充<span class="product-name product-name--after-text">采标集</span>版本、浏览器和操作系统信息。你可以在管理页的 **“关于”** 中查看这些信息，再按下面的模板整理反馈：

```text
问题类型：安装 / 更新 / 归档 / 登录 / 权益 / 功能建议 / 其他
发生时间：
采标集版本：
浏览器及版本：
操作系统及版本：
相关公告网址（如有）：
原本希望完成的操作：
问题出现前的操作步骤：
实际出现的情况或错误提示：
必要的截图：
登录邮箱或订单信息（仅账号、订单或权益问题需要）：
```

发送前，请遮挡截图中与问题无关的账号信息、客户资料和项目敏感内容，**不要发送密码、验证码、完整兑换码、标书附件或完整 ZIP 归档包**。

<details class="custom-block details" open>
<summary>补充说明</summary>

还没有安装插件，或暂时无法打开“关于”页面时，可以先提供浏览器名称、操作步骤和当前提示，不必为了补齐版本信息反复卸载或重装。

</details>

整理好后，通过你选择的小红书私信或邮件发送即可。同一问题有新的提示或进展时，可以在原对话或邮件中继续补充，方便对照前面的情况。
