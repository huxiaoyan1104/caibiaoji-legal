# 采标集隐私政策

> 版本：2.0.0 · 修订日期：2026年10月7日 · 生效日期：2026年10月7日

本政策介绍采标集会处理哪些信息、为什么需要这些信息，以及你在使用归档资料时需要遵守的要求。如果需要处理个人信息相关事项，你也可以在本政策中了解联系方式。

本版中的云端归档说明适用于采标集 2.0.0；各渠道可安装的版本请以对应商店或安装入口为准。

## 1. 适用范围

本政策适用于采标集浏览器插件，以及相关的云端归档记录、账号、权益和技术支持服务。使用采标集时，你可以在支持的政府采购公告详情页主动发起归档，将生成的归档包保存到自己的设备中。采标集的个人信息处理者及运营主体为胡小燕（自然人），联系邮箱为 support@fun8.top。

采标集只面向具有完全民事行为能力的成年人提供购买、注册和使用服务。未成年人不得购买、注册或使用本服务。

采标集提供资料整理、本地归档包生成和云端归档记录查看功能。你对归档资料进行取得、保存、复制、使用、转交、公开或其他后续处理时，应自行确认具有必要授权和合法依据，并遵守适用法律法规、来源网站规则以及知识产权、商业秘密、个人信息与数据安全、采购保密等要求。资料能够公开访问，不等于可以不受限制地使用。

采标集依法承担自身个人信息处理活动中的告知、安全保护和权利响应义务。个人信息相关问题可以通过本政策列明的支持邮箱联系我们。

## 2. 在本地处理的信息

在你主动发起归档后，采标集会解析当前公告中的项目信息，并获取归档所需的公告内容及公开附件。在你的设备中，插件会生成网页原文、Excel 清单和 ZIP 归档包，并临时保存任务恢复所需的文件与状态。附件文件、Excel 清单和完整 ZIP 归档包不会作为归档文件上传至采标集服务器。

归档记录与用于历史预览的公告页面快照会按下节说明保存到云端。页面快照是公告内容的图像副本，可能包含公告中展示的联系人及其他信息。

ZIP 命名设置、任务恢复信息及临时文件等仍保存在当前浏览器中。设置和本机文件不会因你在另一台设备登录同一账号而自动同步过去。

归档包保存到你的设备后，由你决定访问权限、保留期限、对外提供和删除方式。资料中如含个人信息、商业秘密或其他受保护内容，请按业务所需的最小范围处理，采取适当的访问控制，并在目的完成后依法处置。不要利用插件非法获取、使用或披露资料，也不要绕过登录、验证码、签名、限流或其他访问控制。

## 3. 提交至采标集服务器的信息

采标集会处理你输入的邮箱和登录验证码，用于注册账号、验证身份并保持登录状态。选择密码登录、设置、修改或重置密码时，也会处理你在对应表单中输入的密码，用于账号验证或更新登录凭据。兑换权益时，你输入的兑换码会通过受保护的连接发送至采标集服务器进行验证（请只在采标集的兑换输入框中提交完整兑换码）。

为管理你的归档权益，采标集会处理账号、订单、兑换记录、套餐信息及权益使用状态。在确认可用权益和记录归档结果时，采标集会提交归档任务编号、项目编号及必要的结果状态，用于核对权益、避免重复扣次并完成权益结算。

为便于你在换设备或重装后查看归档历史，采标集会将你主动发起的归档记录保存到当前账号。记录包括公告链接、标题、来源网站、归档时间和操作入口，已解析的项目名称、编号、标段、公告类型及截止时间，以及归档阶段、结果状态、文件名称、大小、层级和处理结果等清单信息。需要定位本机文件时，还会保存相应的浏览器下载记录标识。

用于历史预览的 JPEG 公告页面快照会上传至采标集使用的阿里云对象存储服务。快照包含公告页面的图像内容；原始附件文件、Excel 清单和完整 ZIP 归档包不随云端记录上传。

归档失败或取消时，已经保存的记录及处理状态仍可能显示在历史中。你可以在其他设备登录同一账号后查看已保存的云端记录和可用快照，但不能从云端历史恢复另一台设备上的 ZIP 归档包或附件。本版本不上传、迁移或展示旧版本仅保存在本机的归档历史。

为控制请求频率、保护账号和服务安全、防止滥用，以及维护服务和排查故障，采标集可能会处理请求 IP 地址、采标集版本、浏览器类型、随机生成的安装标识、事件发生时间和运行状态。IP 地址不会用于获取 GPS 位置或精确地理位置。登录账号、查看或兑换权益、查看云端归档历史，以及归档前确认可用权益，都需要连接采标集服务器，因此无法完全离线使用。

## 4. 浏览器权限与访问范围

采标集使用网页访问和脚本相关权限识别支持的公告、显示工作台，并下载你主动归档所需的公开 HTTPS 附件。下载权限用于保存归档包，以及通过浏览器下载记录查找文件；存储权限用于保存登录状态、本机缓存、设置及任务恢复所需的信息。侧边栏和右键菜单相关权限用于提供操作入口，后台处理能力则用于执行归档任务。

采标集申请了覆盖 HTTPS 网站的访问权限，以便下载来自不同网站的公告附件。授予这些权限并不意味着插件会自动采集任意网站的内容。归档仍须由你主动发起，插件不会绕过采购网站的登录、验证码、签名或访问限制。

## 5. 服务商与外部网站

采标集的账号验证、云端归档记录与快照存储、服务器运行、故障排查记录和支付交付，可能需要相关服务商协助完成。

目前，账号与权益服务正式使用的接口（API）、数据库、缓存、故障排查日志及账号核验相关服务，均部署或配置在阿里云中国大陆华东 1（杭州）地域。用于保存公告页面快照的阿里云 OSS 也配置在该地域。

爱发电负责其平台内的支付和订单处理。即使使用相同邮箱，采标集账号与爱发电账号也不会自动绑定。

如你自行使用由境外服务商提供的邮箱接收账号核验信息，相关邮箱地址及核验信息可能由该邮箱服务商在境外接收和处理。

下载附件时，采标集会直接访问公告网站或提供附件文件的网站。如果你打开爱发电或技术支持中的外部页面，相关网站会按照各自的规则处理你的访问。因此，在使用这些外部服务前，请先阅读其隐私说明。

采标集对通过浏览器扩展权限取得的信息，仅用于提供或改进政府采购公开招标公告归档这一单一用途。在 Microsoft Edge 版本中，我们遵守 Microsoft Edge Add-ons 开发者政策及适用的数据使用与隐私要求；在 Chrome 版本中，我们同时遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。我们不会出售这些信息，不会将其用于个性化广告、信用评估或放贷，也不会允许人工读取，除非用户对特定内容给予明确同意、为安全和防止滥用所必需、为履行适用法律义务所必需，或仅使用经汇总且匿名化的数据开展内部运营。

## 6. 保存期限与安全

已下载的 ZIP 归档包保存在你的设备中，由你自行管理。云端归档记录和仍被有效记录引用的页面快照，当前不会按记录年龄自动淘汰。插件目前不提供单条删除或清空云端历史的自助入口；需要办理个人信息相关事项时，可以按下一节说明联系我们。

退出登录、卸载插件或清除浏览器扩展数据，不会自动删除已保存的云端归档记录和快照。重新安装或换设备后，需要登录同一账号并连接服务器，才能查看这些记录。本机设置、缓存和任务恢复信息会受到清理扩展数据或卸载的影响；已经下载到电脑的 ZIP 归档包不会随插件卸载而删除。

旧版本仅保存在本机的归档历史不纳入本版本的云端历史。升级、清理数据或更换设备前，请保存好仍需使用的实际归档包，不要把云端记录当作附件或完整归档包的备份。

后台会清理无效上传或不再被有效记录引用的页面快照。该清理机制不等于按时间删除正常归档记录，也不会提供已删除本机文件的恢复功能。

登录验证码有效期为 10 分钟。用于排查故障和了解运行情况的最小必要记录，会在阿里云日志服务（SLS）中保存 30 天。账号、订单、权益、退款、验证和安全记录会在提供服务、处理交易、解决争议、保障安全及履行法定义务所需的最短期限内保存。账号注销后，将删除或匿名化不再需要继续保存的信息；法律法规另有保存要求的除外。

请勿通过技术支持渠道发送密码、登录验证码、完整兑换码、标书附件或完整归档包。

## 7. 查阅、更正、删除与注销

如果需要查阅、更正或删除个人信息、注销账号，或撤回同意，你可以通过支持邮箱提出申请。请在申请中说明希望办理的事项和登录邮箱。为保护账号安全，我们可能会先核验身份，再处理你的申请。

采标集目前没有自助注销账号的入口。如果需要注销账号或处理个人信息，请发送邮件至 support@fun8.top（退出登录不会注销账号，也不会自动删除云端归档记录和页面快照、已保存到设备中的归档包，或依法需要保留的订单记录）。

## 8. 政策更新与联系我们

隐私政策更新时，我们会说明版本、更新日期和生效日期。如果信息处理的目的、方式或种类发生变化，我们会根据实际处理依据和适用要求告知你，并在需要时请你确认相关变更。

支持邮箱：support@fun8.top。服务时间：周一至周五 09:00–18:00（北京时间，GMT+8）。请勿在支持邮件中发送密码、登录验证码、完整兑换码或标书附件。
