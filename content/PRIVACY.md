# 采标集隐私政策

> 版本：2026-09-08 · 更新日期：2026年9月8日 · 生效日期：2026年9月8日

本政策说明采标集处理哪些信息、用于什么目的、你使用归档资料时应遵守的边界，以及你如何联系我们处理个人信息相关请求。

## 1. 适用范围

本政策适用于采标集浏览器插件及其账号、权益和支持服务。采标集帮助你在支持的政府采购公告详情页主动发起归档，生成保存在本机的归档包。

个人信息处理者及运营主体为胡小燕（自然人），联系邮箱为 support@fun8.top。

采标集只面向具有完全民事行为能力的成年人提供购买、注册和使用服务。未成年人不得购买、注册或使用本服务。

采标集只提供资料整理与本地归档工具。你对归档资料进行取得、保存、复制、使用、转交、公开或其他后续处理时，应自行确认具有必要授权和合法依据，并遵守适用法律法规、来源网站规则以及知识产权、商业秘密、个人信息与数据安全、采购保密等要求。资料能够公开访问，不等于可以不受限制地使用。

采标集依法承担自身个人信息处理活动中的告知、安全保护和权利响应义务。个人信息相关问题可以通过本政策列明的支持邮箱联系我们。

## 2. 在本地处理的信息

在你主动归档时，插件读取当前公告的项目字段、正文、公开附件链接及文件，并在本机处理网页原文、截图、Excel 清单和 ZIP。公告正文、截图、附件和归档包不作为归档内容上传至采标集服务端。

本地历史保存公告链接、项目字段、归档状态、文件清单及用于预览的公告快照；账号间按本地范围隔离。任务进行中可能暂存附件，以支持任务恢复。历史记录不会自动同步到其他设备；退出登录不等于删除本地历史或磁盘归档包。

归档包保存到你的设备后，由你决定访问权限、保留期限、对外提供和删除方式。资料中如含个人信息、商业秘密或其他受保护内容，请按业务所需的最小范围处理，采取适当的访问控制，并在目的完成后依法处置。不要利用插件非法获取、使用或披露资料，也不要绕过登录、验证码、签名、限流或其他访问控制。

## 3. 提交至服务端的信息

账号服务处理你输入的邮箱和登录验证码，用于账号注册、身份核验和维护会话。兑换时，兑换码会通过受保护的连接提交服务端校验；请只在插件的兑换输入框提交完整兑换码。

权益服务处理账号、订单与兑换记录、套餐及消费状态。归档许可和结算请求包含任务标识、项目编号及必要的结果状态，用于核对权益、避免重复扣次和完成结算；不包含公告正文或附件文件。

为了实施接口限流、保障账号与服务安全、防止滥用、维护服务和排查故障，服务可能处理请求 IP 地址、插件版本、浏览器类型、随机安装标识、事件时间和运行状态。IP 地址不用于获取 GPS 或精确地理位置。采标集并非完全离线服务；账号、权益和归档许可需要连接服务端。

## 4. 浏览器权限与访问范围

网页访问和脚本相关权限用于识别受支持公告、提供工作台，以及下载你主动归档所需的公开 HTTPS 附件；下载权限用于保存归档包和定位下载记录。存储权限用于会话、历史、配置和任务恢复；侧边栏、右键菜单及后台处理能力用于相应操作入口和任务执行。

广泛的 HTTPS 主机权限用于处理附件来自不同域名的情况，不代表插件提供任意网站的自动采集。归档须由你主动触发，插件不绕过采购网站的登录、验证码、签名或访问限制。

## 5. 服务商与外部网站

账号验证、服务器运行、诊断日志及支付交付可能由相应服务商协助提供。采标集当前用于账号与权益服务的生产 API、数据库、缓存、诊断日志及账号核验相关服务均部署或配置在阿里云中国大陆华东 1（杭州）地域。爱发电承担其平台内的支付与订单流程；插件账号与爱发电账号不会仅因邮箱相同而自动绑定。

如你自行使用由境外服务商提供的邮箱接收账号核验信息，相关邮箱地址及核验信息可能由该邮箱服务商在境外接收和处理。

下载附件会直接访问公告网站或其文件服务；打开爱发电或技术支持中的外部页面后，相关网站按照自身规则处理访问。请在使用外部服务前阅读其隐私说明。

采标集对通过浏览器扩展权限取得的信息，仅用于提供或改进政府采购公开招标公告归档这一单一用途。在 Microsoft Edge 版本中，我们遵守 Microsoft Edge Add-ons 开发者政策及适用的数据使用与隐私要求；在 Chrome 版本中，我们同时遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。我们不会出售这些信息，不会将其用于个性化广告、信用评估或放贷，也不会允许人工读取，除非用户对特定内容给予明确同意、为安全和防止滥用所必需、为履行适用法律义务所必需，或仅使用经汇总且匿名化的数据开展内部运营。

## 6. 保存期限与安全

公告处理文件和归档历史主要保存在你的设备；保存到磁盘的 ZIP 由你自行管理。插件目前不提供单条历史记录删除入口。退出登录不会删除本地历史或磁盘中的归档包；清理浏览器扩展数据或卸载扩展可能导致本地记录丢失。

登录验证码有效期为 10 分钟。SLS 中的最小必要诊断事件保存 30 天。账号、订单、权益、退款、验证和安全记录会在提供服务、处理交易、解决争议、保障安全及履行法定义务所需的最短期限内保存。账号注销后，将删除或匿名化不再需要继续保存的信息；法律法规另有保存要求的除外。

请勿通过技术支持渠道发送密码、登录验证码、完整兑换码、标书附件或完整归档包。

## 7. 查阅、更正、删除与注销

你可以通过支持邮箱提出查阅、更正、删除、注销账号或撤回同意等请求。请说明请求类型和登录邮箱；为保护账号，处理前可能需要进行必要的身份核验。

插件目前不提供自助注销按钮。退出登录不是注销，也不会自动删除本地历史、磁盘归档包或依法需要保留的订单记录。需要注销账号或处理个人信息时，请联系 support@fun8.top。

## 8. 政策更新与联系我们

隐私政策更新时会说明版本、更新日期和生效日期；涉及处理目的、方式或种类等变化时，应按实际处理依据和适用要求履行告知及必要的确认程序。

支持邮箱：support@fun8.top。服务时间：周一至周五 09:00–18:00（北京时间，GMT+8）。请勿在支持邮件中发送密码、登录验证码、完整兑换码或标书附件。
