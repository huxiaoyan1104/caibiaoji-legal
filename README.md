# 采标集协议公开站

本项目用于公开发布采标集的三份正式协议：

- 隐私政策：`/privacy/`
- 服务协议：`/terms/`
- 退款协议：`/refund/`

当前版本：2026-09-07，生效日期：2026年9月7日。

## 本地构建

需要 Node.js 20 或更高版本，不需要安装第三方依赖。

```bash
npm run build
npm run check
```

三份 Markdown 位于 `content/`。修改正文后必须重新执行构建并提交同步生成的 HTML，不能直接分别修改网页正文。

## GitHub Pages

仓库使用无框架静态文件，可直接选择从 `main` 分支根目录发布。启用后检查首页及三个协议地址均可在未登录状态下访问。

## 内容边界

本仓库只保存公开协议与静态页面资源，不保存插件源码、内部评审、订单、账号、密钥或测试证据。
